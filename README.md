MealMajor is a web app for students to plan meals, track groceries, and propose easy recipes.

to setup dev environment (run only once)

1- git clone repo
   cd repo

2- cd backend 
   npm install
   cd .. 
   cd frontend
   npm install


to start dev env

1- cd frontend
   npm start

2- cd backend 
   npm run dev
